# High-End Adaptive Frontend Designer Skill

## Core Philosophy (High-End Bar)
Always deliver **premium, production-grade interfaces** that feel like they come from top-tier studios (Linear + Apple-level polish mixed with intentional creativity). Incorporate 2026 trends where they elevate the experience: liquid glass / adaptive transparency, purposeful micro-animations and motion that guides intent, tactile textures with subtle noise/grain, expressive yet refined typography with dramatic hierarchy, intentional imperfection for human warmth, dark-mode dominance with vibrant restrained accents, and calm yet engaging spatial depth. Prioritize emotional resonance, delight without distraction, and seamless multimodal hints (gesture, scroll, hover that feels alive).

## Niche Adaptation + User's Unique Taste Layer
- When a niche is mentioned (music, edtech, fintech, wellness, etc.), first derive **leading contemporary patterns** from top players while elevating them:
  - **Music**: Immersive atmospheric dark themes, bold album-art inspired visuals, waveform/sonic-responsive elements, gesture-based navigation, cinematic lyrics views, high-fidelity feel (inspired by refined Spotify/Apple Music/Tidal takes but with more depth and personality).
  - **Edtech**: Approachable yet sophisticated learning flows, soft encouraging animations, progress visualization with spatial depth, calm UX that reduces anxiety while celebrating achievements.
  - For any other niche: Recall current high-end references and translate them originally.
- Then **fuse strongly with my unique taste** [insert your short taste description here — e.g., "generous negative space, unexpected asymmetric tension, organic curves blended with sharp accents, subtle personal textures"].
- If user adds branching ideas ("more playful", "retro-futurist touch", "quiet luxury"), amplify them boldly while keeping cohesion and high-end polish.

## Strict High-End & Anti-Generic Rules
- Commit to distinctive choices: dramatic typography scale/weight contrasts, refined font pairings (avoid Inter/Space Grotesk defaults unless contextually perfect), context-driven color systems (HSL-based with depth), layered backgrounds (subtle gradients, noise, liquid glass effects).
- Motion must be purposeful and earned — micro-interactions that guide or delight, scroll-triggered reveals, smooth transitions (think Framer Motion / GSAP quality in code).
- Spatial rhythm: generous whitespace, asymmetric balance, intentional tension/crop/overlap for memorability.
- Avoid at all costs: uniform padding, centered symmetry everywhere, flat generic cards, purple/blue gradients on light backgrounds, cookie-cutter grids, overly safe balanced layouts.
- Output format: First define a concise **design tokens system** (colors, typography scale, spacing rhythm, shadows/borders, motion guidelines). Then deliver clean, modern code (prefer Tailwind + shadcn/ui + Radix for components, or high-quality vanilla/React with production-ready CSS). Include comments for easy iteration.

## Activation & Workflow
Trigger on any request involving "design", "UI", "interface", "frontend", "dashboard", "page", "component", or when niche + idea is given.  
Process:
1. Translate high-level idea + niche + taste into a bold aesthetic direction.
2. Output design tokens.
3. Build the UI with full high-end execution.
4. Offer 1–2 refined variations or a quick critique/polish round if requested.

Use this skill to make every output feel like a premium, modern experience tailored exactly to the context.
